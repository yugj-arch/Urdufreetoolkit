# Urdu Toolkit

Pull Urdu out of images, transliterate to Devanagari + Roman, and compare
engines side by side.

- **App + full docs:** [`urdu-free-toolkit/README.md`](urdu-free-toolkit/README.md)
- **Deploy — Vercel** (cloud engines only): [`urdu-free-toolkit/DEPLOY.md`](urdu-free-toolkit/DEPLOY.md)
- **Deploy — Hugging Face Space / Docker** (all engines, incl. PaddleOCR +
  EasyOCR): [`urdu-free-toolkit/DEPLOY-HF.md`](urdu-free-toolkit/DEPLOY-HF.md)

The YAML block above is the Hugging Face Space card — it configures the Docker
Space that builds from the root `Dockerfile`.
